Create a stunning, premium, modern, fully responsive website for a female-owned plumbing company called **P&E Plumbing**.

The website should feel like a real, established plumbing business website — NOT like a generic AI-generated template.

## Overall Design Direction

Create a sophisticated, premium and trustworthy visual identity for P&E Plumbing.

The business is female-owned, so the design should feel elegant and modern while still looking professional, reliable and strong enough for a plumbing company.

Use a beautiful combination of:

* Deep navy / dark charcoal
* White
* Soft warm beige
* Subtle copper or rose-gold accent
* Very light blue accent where appropriate

Avoid an overly masculine construction-company look.

The design should communicate:
**Trust • Clean Work • Professionalism • Reliability • Quality**

Use modern typography with excellent spacing and hierarchy.

The website should look polished enough that it could realistically be used by a professional plumbing company.
